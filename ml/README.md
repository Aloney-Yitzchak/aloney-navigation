# ml — מודל זיהוי המבנים

| מטלה | מה נכנס לכאן |
| --- | --- |
| T20 | `labels.txt` ותיעוד האיסוף (מה צולם, מתי, מאיזה זווית). התמונות עצמן לא נכנסות ל-git |
| T21 | מחברת האימון, דוח ההערכה ומטריצת הבלבול |

## איסוף התמונות (T20)

1. **מסך הצוות ← "צילום מבנים למודל"**: מוסיפים כל מבנה ("מבנה חדש"), עם הערה מאיפה לצלם. המשימה "אחר" (שבילים, עצים, שמיים) נוצרת לבד.
2. **מצלמים**: לוחצים על מבנה, ומצלמים 30–50 תמונות מזוויות, מרחקים ושעות שונים. בלי אנשים בתמונה. המונה מתעדכן בכל הטלפונות.
3. **מייצאים**: "ייצוא zip" ושומרים ב-Drive. מבנה הקובץ: `dataset/<label>/*.jpg`, `labels.txt`, `tasks.csv`.
4. **מוחקים מהטלפון** (תפריט ⋮) רק אחרי שהקובץ שמור.
5. את `labels.txt` מהקובץ מעתיקים לכאן. התמונות עצמן לא נכנסות ל-git.

### רשימת המבנים

`ml/buildings.csv` ו-`ml/labels.txt` נוצרים מנתוני הקמפוס ומ-OpenStreetMap:

<div dir="ltr">

```bash
python campus-data/merge_osm.py --download   # once, for the OSM files
python ml/make_buildings.py                   # → ml/buildings.csv, ml/labels.txt
python ml/seed_photo_tasks.py                 # in Cloud Shell: the list in the app (30 photos each)
```

</div>

ברשימה כל מבנה שיש בו חדר מהשיבוץ (או מבנה עד 10 מ' ממנו), וכל מבנה עם שם ב-OSM בתוך הכפר: חדר אוכל, ספרייה, אולם ספורט, בית המוסיקה, פנימיות. כל מבנה מקבל תווית קבועה, `building_01` עד `building_26`, מצפון לדרום. התווית היא שם התיקייה ו-class של המודל. את השם אפשר לשנות באפליקציה. המרכז (lat, lng) משמש את T22, כדי לבדוק שהמבנה שזוהה קרוב למשתמש.

### פרוטוקול הצילום

| מה | כמה |
| --- | --- |
| תמונות לכל מבנה | לפחות 30 (יעד 40–50 אחרי הערכה ראשונה, T21) |
| "אחר" | כמו מבנה: שבילים, דשא, עצים, שמיים, גדרות, רכבים |
| ימים | לפחות 2 ימים שונים, ובשעות שונות: בוקר, צהריים, אחר הצהריים |
| זוויות | מכל שביל שמגיע למבנה, כמו שמי שהולך בו רואה; גם מקרוב (כניסה, שלט) וגם מרחוק (כל המבנה) |
| אנשים | בלי אנשים מזוהים: מחכים שיעברו, או מוחקים מיד ("מחיקת התמונה האחרונה") |

- **מבנים שנראים דומים** (כיתות טרומיות סמוכות): כדאי לצלם בכל אחד את מה שמייחד אותו (שלט, צבע, עץ ליד), ולרשום את זה בהערה של המשימה.
- **אחרי כל יום צילום:** "ייצוא zip", שומרים ב-Drive בתיקייה `aloney-navigation/dataset/<תאריך>`, ומוחקים מהטלפון.
- **החלוקה לאימון ובדיקה (T21)** לפי יום הצילום, ולא לפי תמונה בודדת, כדי שתמונות מאותו רגע לא יהיו בשתי הקבוצות (SDD 10, שלב 2).
