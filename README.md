# ניווט אלוני יצחק

אפליקציית Android שמובילה תלמידים, מורים ואורחים מכל מקום בקמפוס של כפר הנוער אלוני יצחק אל כל חדר — בחצים על גבי המצלמה (AR) ובמפה דו-ממדית.

הפרויקט הוא דוגמה מלאה לפרויקט גמר בהנדסת תוכנה, חלופת תכנות טלפונים חכמים (883589): מהגדרת הדרישות, דרך התכנון והפיתוח, ועד תיק הפרויקט שמוגש לבחינה.
