# הנחיות משרד החינוך

סיכום של שני המסמכים הרשמיים לחלופת תכנות טלפונים חכמים (883589): ההנחיות לכתיבת תיק הפרויקט, ומחוון 5 יח"ל. לפני הגשה בודקים תמיד מול הגרסה העדכנית ב[פורטל המגמה](https://pop.education.gov.il/tchumey_daat/computer-science-software-engineering-cyber/high-school/pedagogy-of/high-school-software-cyber-engineering/).

## מבנה תיק הפרויקט

| פרק | מה נכנס | איפה אצלנו |
| --- | --- | --- |
| שער | לוגו, שם בית הספר, שם העבודה, שם התלמיד, ת.ז., מנחה, חלופה, תאריך | [תיק הפרויקט](תיק-פרויקט) |
| תוכן עניינים | אוטומטי, לפי כותרת 1–3 | |
| טבלת תכולות | מה מומש, לפי סעיפי המחוון | |
| מבוא | רקע, תהליך המחקר, אתגרים, חידושים, תיאור תחום הידע | פרק 1 |
| מבנה / ארכיטקטורה | מסך הפתיחה, תיעוד כל מסך, תרשים מסכים, תרשים מחלקות UML | פרק 2 |
| מימוש | לכל מחלקה: תפקיד, תכונות, פעולות עם קוד; תרשימי זרימה; בסיס הנתונים | פרק 3 |
| מדריך למשתמש | גרסאות שנבדקו, אופן הפעולה, הודעות, מגבלות | פרק 4 |
| רפלקציה | תהליך, למידה, תובנות, מה הייתי עושה אחרת — חצי עמוד עד עמוד | פרק 5 |
| ביבליוגרפיה | לפי APA, כולל קישורים לשיחות AI שמהן יובא קוד | פרק 6 |
| נספחים | קוד המחלקות כטקסט עם Javadoc | פרק 7 |

**עיצוב:** גופן David או Arial עד 12, כותרת עליונה עם שם התלמיד והפרויקט, כותרת תחתונה עם מספר עמוד.

**קוד מבינה מלאכותית:** כל קטע קוד משמעותי שנוצר בכלי AI מסומן בבירור בתיק, מופיע בביבליוגרפיה עם קישור ציבורי, ומספר המקור מצוין ב-Javadoc.

## סעיפי התכולה במחוון (1–10)

| סעיף | מה נדרש |
| --- | --- |
| 1–5 | **תנאי סף:** אפליקציית Android, עבודה בלי קריסות בבחינה, לוגיקה מורכבת, ממשק עם כמה מסכים, אירועים והרשאות. בלעדיהם הציון 0 |
| 6 | לפחות **2** נושאים מרשימה (Service, מסד נתונים עם יחסים ו-JOIN, RecyclerView, MVVM, GenAI דרך API ועוד) |
| 7 | **בסיס נתונים** עם כתיבה וקריאה. SharedPreferences, קובץ טקסט או JSON לא נחשבים. בסיס נתונים מרוחק נחשב גם כשני נושאים מסעיף 10 |
| 8 | לפחות 3 נושאים מסעיף 9, **או** לפחות 2 מסעיף 9 ו-2 מסעיף 10 |
| 9 | נושאים מתקדמים: מפות ונתוני מיקום, מאזיני מיקום ותנועה, מנוע אלגוריתמי ("בינה אנושית"), למידת מכונה עם איסוף, אימון והטמעה, ועוד |
| 10 | נושאים נוספים: מצלמה, GPS, חיישנים, TextToSpeech ועוד |

איך הפרויקט שלנו עונה על כל סעיף: [תיק הפרויקט — טבלת תכולות](תיק-פרויקט), והנימוק לכל בחירה: [מסמך התיכון, סעיף 2.2](מסמך-תיכון-SDD).
